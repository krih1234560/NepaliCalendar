# Nepali Calendar

A fast Nepali Bikram Sambat calendar for the web.

## Features

- Nepali Calendar
- नेपाली पात्रो
- BS to AD conversion
- AD to BS conversion
- BS 1975–2100 navigation
- Nepali numerals
- Festival search
- Holiday search
- Moon phase
- Nepali Unicode tool
- Age calculator
- Date difference tool
- Mobile responsive
- SEO friendly HTML

## Technology

- HTML
- CSS
- JavaScript
- Vite
- @grahan/calendars
